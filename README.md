# Tibro VPN

VPN клиент для OpenWrt на базе xray-core. Разработан для обхода DPI фильтрации Turkmentelecom.

## Возможности

- xray-core с поддержкой xhttp, WS, gRPC транспортов
- TPROXY — прозрачный прокси для всей LAN
- Два провайдера: Remnawave и Happ
- Веб UI через CGI (без LuCI)
- Autostart после перезагрузки
- Watchdog для автовосстановления туннеля
- Автообновление подписок через cron

## Совместимость

- OpenWrt 25.12.x
- Архитектура: aarch64_cortex-a53
- Тестировано на: Xiaomi Redmi AX6S (AX3200)
